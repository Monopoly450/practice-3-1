# Task 7: избранное — объяснение по шагам

## 1. Что добавлено

В каталоге уже есть класс `BookCatalog`, который хранит книги и умеет добавлять,
удалять, искать и сортировать их. Для избранного создан отдельный класс `Wishlist`
в `src/task7-wishlist.ts`.

В тексте задания встречаются два имени файла: `task7-wishlist.ts` и `wishlist.ts`.
Использовано первое, потому что оно соответствует нумерации практики и импорту
в предоставленных тестах. Сам файл тестов перенесён из `src` в `tests/task7.test.ts`.

## 2. Почему избранное хранит только идентификаторы

У каталога есть полные объекты:

```ts
{ id: '1', title: 'TypeScript Guide', authors: ['John Doe'], year: 2024 }
```

Избранному достаточно массива:

```ts
['1', '3']
```

Название, авторы и год не копируются. Если данные книги в каталоге изменятся,
следующий вызов `getFavorites` получит актуальные данные. Не нужно синхронизировать
две независимые копии книги. Каталог служит единым источником истины о книгах.

## 3. Поле и конструктор Wishlist

```ts
private favoriteIds: string[] = [];

constructor(favoriteIds: string[] = []) {
  this.favoriteIds = [...new Set(favoriteIds)];
}
```

- `private` запрещает обращаться к полю напрямую из другого TypeScript-кода.
- `string[]` означает массив строк — идентификаторов книг.
- `= []` задаёт пустое начальное значение.
- Конструктор позволяет создать пустое избранное или восстановить сохранённые id.
- `Set` убирает повторяющиеся id, сохраняя порядок первого появления.
- Оператор `...` разворачивает значения в новый массив. Внешний массив не становится
  внутренним состоянием класса, поэтому его последующее изменение не испортит Wishlist.

`private` здесь — проверка доступа компилятором TypeScript; это не шифрование данных.

## 4. Проверка и переключение избранного

```ts
public has(id: string): boolean {
  return this.favoriteIds.includes(id);
}
```

`includes` проверяет, есть ли строка в массиве, и возвращает `true` или `false`.
Метод ничего не меняет. Его используют и кнопка, и другие методы класса.

```ts
public toggle(id: string): void {
  if (this.has(id)) {
    this.favoriteIds = this.favoriteIds.filter((favoriteId) => favoriteId !== id);
  } else {
    this.favoriteIds = [...this.favoriteIds, id];
  }
}
```

`toggle` означает «переключить состояние».
Если id найден, `filter` создаёт новый массив без него.
Если id не найден, создаётся новый массив со старым содержимым и id в конце.
`void` означает, что результат не возвращается: метод меняет состояние экземпляра.

Пример последовательности:

```text
Начало:       []
toggle('1'):  ['1']
toggle('2'):  ['1', '2']
toggle('1'):  ['2']
```

## 5. Получение книг и зависимость через параметр

```ts
public getFavorites(catalog: BookCatalog): Book[] {
  return catalog.getBooks().filter((book) => this.has(book.id));
}
```

Здесь три действия:

1. Метод получает готовый экземпляр `BookCatalog` через параметр `catalog`.
2. `getBooks()` возвращает массив актуальных книг каталога.
3. `filter` оставляет книги, для которых `has(book.id)` вернул `true`.

Порядок результата соответствует порядку книг в каталоге. Например, если
избранное хранит `['3', '1']`, а каталог содержит книги `1, 2, 3`, результат — `1, 3`.

Это **внедрение зависимости через параметр метода**. `Wishlist` использует каталог
во время вызова, но не сохраняет его в поле и не создаёт его самостоятельно.
В этой модели связь с каталогом — зависимость; Wishlist не владеет книгами.

Важно различать: `favoriteIds` содержит строковые значения id, а результат
`getFavorites` — новый массив с актуальными объектами из каталога. Метод не делает
глубокие копии книг и не сохраняет полученные объекты внутри Wishlist.

В предоставленном тесте есть подпись `getFavorites (композиция)`. Это только имя
группы тестов; описанная в задании и реализованная связь — зависимость через параметр.

## 6. Вспомогательные getIds и count

```ts
public getIds(): string[] {
  return [...this.favoriteIds];
}

public get count(): number {
  return this.favoriteIds.length;
}
```

`getIds()` нужен для сохранения: он возвращает копию массива и сохраняет
инкапсуляцию. Внешний код не получает сам приватный массив.

Геттер `count` требуется предоставленными тестами. Он используется как свойство:
`wishlist.count`, без круглых скобок. Это число сохранённых id, а не обязательно
число отображаемых книг: id удалённой книги может оставаться в избранном.
Число существующих избранных книг можно получить через
`wishlist.getFavorites(catalog).length`.

## 7. Общая функция создания карточек

В `main.ts` создание карточки вынесено в функцию:

```ts
function createBookCard(book: Book): HTMLDivElement
```

Она создаёт контейнер, название, рейтинг при наличии, кнопки «Удалить» и
«Избранное», а затем возвращает готовый `div`.

Её переиспользуют обе функции отрисовки:

```ts
bookList.append(createBookCard(book));
wishlistContainer.append(createBookCard(book));
```

Поэтому у двух списков одинаковые карточки и обработчики. Исправление карточки
понадобится внести только в одном месте.

Это два отдельных DOM-элемента для отображения одной книги. Дублирование
отображения не создаёт вторую запись о книге в данных.

## 8. Как работает кнопка «Избранное»

Надпись зависит от состояния:

```ts
favBtn.textContent = wishlist.has(book.id) ? '❤️ В избранном' : '🤍 В избранное';
```

Тернарный оператор выбирает первый текст при `true`, второй — при `false`.
Дополнительно `aria-pressed` сообщает выбранное состояние вспомогательным
технологиям.

После клика выполняется:

```ts
wishlist.toggle(book.id);
saveWishlist();
refreshList();
renderWishlist();
```

Сначала меняются данные, затем они сохраняются, после этого перерисовывается
интерфейс. `refreshList()` заново применяет текущие поиск, фильтры и сортировку
основного списка. Поэтому нажатие на сердечко не сбрасывает выбранные условия.

`renderWishlist()` обновляет отдельный блок избранного независимо от фильтров
основного списка.

## 9. Блок «Моё избранное»

В `index.html` после основного списка добавлены:

```html
<h2>Моё избранное</h2>
<div id="wishlistContainer" class="book-list"></div>
```

В `renderWishlist()` контейнер очищается, затем вызывается
`wishlist.getFavorites(catalog)`. Если результат пустой, показывается
«Пока ничего не добавлено». Иначе для каждой книги создаётся карточка.

Функция вызывается при загрузке страницы, добавлении и удалении книги,
а также при переключении избранного.

В `styles.css` добавлены сетка для нового блока и отступы заголовка и кнопок.

## 10. Почему удаление работает без прямой связи с Wishlist

Обработчик удаления вызывает:

```ts
catalog.removeBook(book.id);
saveCatalog();
refreshList();
renderWishlist();
```

Он не удаляет id из Wishlist. При следующей отрисовке `getFavorites` получает
книги каталога, где удалённой книги уже нет. Поэтому книга исчезает из обоих
списков автоматически.

Это видно на примере:

```text
Каталог:      книги 1, 2, 3
Избранные id: 1, 3
На экране:    книги 1, 3

Удаляем книгу 1 из каталога.

Каталог:      книги 2, 3
Избранные id: 1, 3
На экране:    книга 3
```

Если позже в каталог добавить книгу с тем же id, она снова попадёт в результат.
Это ожидаемое следствие ссылок по идентификатору. Обычное добавление через форму
создаёт новый случайный id.

## 11. Сохранение и восстановление после F5

Сохранение:

```ts
localStorage.setItem('wishlist', JSON.stringify(wishlist.getIds()));
```

`localStorage` хранит строки. `JSON.stringify` превращает массив id в строку JSON.
Например, для массива `['1', '3']` значение в хранилище выглядит как `["1","3"]`.

При загрузке приложение:

1. Читает ключ `wishlist`.
2. Применяет `JSON.parse`.
3. Проверяет, что получилось именно массивное значение и все элементы — строки.
4. Передаёт id в `new Wishlist(favoriteIds)`.

Используется новый экземпляр, потому что `JSON.parse` восстанавливает данные,
но не методы класса. При отсутствии сохранения остаётся пустое избранное.
Если JSON повреждён или имеет неверную структуру, приложение продолжает работу
с пустым избранным, а не останавливается с ошибкой.

Каталог сохраняется отдельно под ключом `catalog`, избранное — под ключом `wishlist`.

## Как объяснить решение устно

«Я вынес избранное в отдельный класс Wishlist. Он хранит только массив id,
а сами книги остаются в BookCatalog. Метод toggle добавляет или убирает id,
has проверяет наличие. Чтобы получить полные книги, я передаю каталог в
getFavorites. Это зависимость через параметр метода. Метод берёт актуальные
книги и фильтрует их по сохранённым id, поэтому удалённая из каталога книга
автоматически исчезает из избранного. Для интерфейса я вынес создание карточки
в общую функцию и использовал её в двух списках. После изменения состояния
сохраняю массив id в localStorage и обновляю оба списка. При перезагрузке
читаю JSON и создаю новый экземпляр Wishlist с сохранёнными идентификаторами».
