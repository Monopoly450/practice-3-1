# Аудит функций src/

Аудит проведён после подключения `BookCatalog` в `main.ts`. Учитываются прямые
и косвенные вызовы приложения. Вызовы только из тестов не считаются использованием
в приложении.

| Название функции | Где находится | Полезная ли она? (Да/Нет) | Как её можно использовать в будущем? (Идея для фичи) |
| :--- | :--- | :--- | :--- |
| calculateAverageYear | src/task1-types.ts | Да | Показать средний год издания в статистике коллекции. |
| addBook | src/task2-functions.ts | Да | Создавать новые версии каталога-словаря для истории изменений и отмены действий. |
| removeBook | src/task2-functions.ts | Да | Сохранять предыдущую версию каталога-словаря при удалении для отмены действия. |
| getBook | src/task2-functions.ts | Да | Открывать карточку книги по идентификатору из ссылки в каталоге-словаре. |
| filterByMinRating | src/task3-filters.ts | Да | Добавить в интерфейс фильтр по минимальному рейтингу. |
| filterAndSortBooks | src/task5-utils.ts | Да | Готовить отсортированные результаты поиска для экспорта без создания экземпляра каталога. |

Эти функции сохранены с JSDoc `@deprecated` и существующими тестами.
Функции из задания 2 работают с неизменяемыми словарями, а методы `BookCatalog` —
с состоянием экземпляра: это разные способы работы с данными, поэтому учебный
функциональный API сохранён для будущей истории версий.

`formatBook`, `createBookFromForm`, `filterByTitle` и `sortBooks` используются
приложением напрямую или через классы. Дублирующая реализация их логики не добавлялась.
`BookClass.format()` — бонусный API для форматирования отдельного экземпляра книги.
